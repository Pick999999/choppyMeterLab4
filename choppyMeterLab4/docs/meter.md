# ⏲️ meter.md - ระบบแสดงผลเข็มไมล์วัดความผันผวน (Choppy Meter Visualization)

### 1. รายการฟังก์ชันทั้งหมด (Function Summary)
สรุปการทำงานของเมธอดภายในคลาส `ChoppyMeter`:

* **constructor(canvasId, options)**: กำหนดค่าเริ่มต้นให้กับเข็มไมล์ เช่น รหัส Canvas, ช่วงคะแนน (0-100), และการตั้งค่าสีตามโซนความผันผวน (เขียว, เหลือง, แดง)
* **resize()**: จัดการปรับขนาดของ Canvas ให้เหมาะสมกับหน้าจอ และรองรับการแสดงผลบนจอความละเอียดสูง (High DPI/Retina)
* **setValue(newValue)**: ตั้งค่าตัวเลขที่ต้องการแสดงผล และเริ่มกระบวนการเคลื่อนที่ของเข็ม (Animation) ไปยังค่าใหม่
* **animate()**: (Internal) ควบคุมการขยับของเข็มไมล์ให้มีความสมูท (Smooth Transition) ไม่กระโดดข้ามไปมา
* **render()**: ฟังก์ชันหลักในการวาดองค์ประกอบทั้งหมดลงบน Canvas รวมถึงการวาดเส้นโค้งแบ่งโซน, เข็มไมล์, และตัวเลขแสดงผล
* **drawGauge()**: (Helper) วาดโครงสร้างหลักของหน้าปัดวงกลมและเข็มชี้

---

### 2. การเรียกใช้ฟังก์ชันและตัวแปรภายนอก (External Dependencies)
ไฟล์นี้เน้นการจัดการกราฟิกแบบ Low-level บนเบราว์เซอร์:

* **HTML5 Canvas API**: ใช้ `getContext('2d')` เพื่อวาดรูปทรงเรขาคณิต (arc, line, fillText) สำหรับสร้างหน้าปัด
* **RequestAnimationFrame**: ใช้ฟังก์ชันมาตรฐานของเบราว์เซอร์เพื่อให้การขยับของเข็มมีความลื่นไหลและประหยัดทรัพยากรเครื่อง
* **DOM API**: เข้าถึง Element ผ่าน `document.getElementById` เพื่อระบุตำแหน่งที่จะวาดไมล์

---

### 3. คุณสมบัติหลัก (Key Features)
* **Visual Status Zones**: แบ่งระดับความผันผวนออกเป็น 3 โซนชัดเจน: 0-38.2 (Trending - เขียว), 38.2-61.8 (Neutral - เหลือง), และ 61.8-100 (Choppy - แดง)
* **Smooth Animation**: เข็มไมล์ไม่ได้แค่ขยับตามตัวเลข แต่มีการคำนวณความเร็วในการกวาดเข็มให้ดูเป็นธรรมชาติ
* **Responsive Design**: มีระบบตรวจจับการเปลี่ยนขนาดหน้าจอ (Resize Listener) เพื่อปรับขนาดหน้าปัดให้พอดีกับ Layout ของ Dashboard ตลอดเวลา
* **High-DPI Support**: รองรับการสเกลภาพให้คมชัด ไม่แตกเบลอเมื่อเปิดบนอุปกรณ์หน้าจอละเอียดสูง
* **Customizable Styles**: สามารถปรับแต่งสีพื้นหลัง, สีเข็ม, และขนาดตัวอักษรได้ผ่านพารามิเตอร์ `options` ในตอนเริ่มสร้าง
