# 📋 details.md - ระบบจัดการหน้าแสดงรายละเอียดและแผงควบคุม (Details Logic)

### 1. รายการฟังก์ชันทั้งหมด (Function Summary)
สรุปการทำงานของฟังก์ชันภายในอ็อบเจกต์ `detailsApp`:

* **init()**: โหลดข้อมูลสินทรัพย์ที่ผู้ใช้เลือกจาก LocalStorage, เริ่มต้นการวาดกราฟ และเชื่อมต่อ API กับ Deriv
* **renderChartContainers()**: สร้างพื้นที่แสดงผลกราฟตามจำนวนสินทรัพย์ที่ถูกเลือกไว้
* **renderTradePanels()**: สร้างแผงควบคุมการเทรด (Trade Panels) สำหรับแต่ละสินทรัพย์ รวมถึงปุ่มกดซื้อและตัวเลือกกลยุทธ์
* **onConnected()**: เมื่อเชื่อมต่อสำเร็จ จะส่งคำขอข้อมูลประวัติ (History) และเริ่มติดตามราคา (Subscribe) ของทุกสินทรัพย์พร้อมกัน
* **onMessage(data)**: จัดการข้อมูลที่ได้รับจาก API ทั้งการวาดแท่งเทียนใหม่ และการอัปเดตสถานะการเชื่อมต่อ
* **updateAnalysis(symbol)**: คำนวณค่าทางเทคนิค (EMA) และวิเคราะห์เงื่อนไขเพื่อเสนอแนะแอ็คชั่น (CALL/PUT) แบบเรียลไทม์
* **updateStatus(text, type)**: อัปเดตสถานะการเชื่อมต่อ (Pill status) บนหน้าจอให้ผู้ใช้ทราบ
* **updateClock()**: อัปเดตนาฬิกาเวลา Server (UTC) เพื่อความแม่นยำในการเข้าออเดอร์

---

### 2. การเรียกใช้ฟังก์ชันและตัวแปรภายนอก (External Dependencies)
ไฟล์นี้ทำหน้าที่เชื่อมโยงระหว่าง UI และระบบเทรดพื้นฐาน:

* **DerivAPI**: ใช้เป็นช่องทางหลักในการเชื่อมต่อ `connect()`, ดึงประวัติ `getHistory()` และรับข้อมูลสด
* **LightweightCharts**: ใช้สร้างอินสแตนซ์ของแผนภูมิและซีรีส์ราคา (Candlestick, Line) สำหรับแต่ละจอ
* **Indicators**: เรียกใช้โมดูลคณิตศาสตร์เพื่อคำนวณเส้น EMA ระยะสั้นและระยะยาว
* **LocalStorage**: ใช้ดึงค่า `selectedAssets` และ `timeframe` ที่ผู้ใช้เลือกไว้จากหน้าหลัก

---

### 3. คุณสมบัติหลัก (Key Features)
* **Dynamic Grid Layout**: จัดการแสดงผลกราฟหลายตัวพร้อมกันตามการเลือกของผู้ใช้ (Multi-Chart Support)
* **Suggested Action Logic**: มีระบบ "แนะนำการตัดสินใจ" อัตโนมัติ โดยวิเคราะห์จากการตัดกันของเส้น EMA
* **Action Lock System**: ผู้ใช้สามารถเลือก "ล็อค" การตัดสินใจเอง หรือให้ระบบแนะนำอัตโนมัติ (Recommended Action) ก็ได้
* **Real-time Price Syncing**: ระบบอัปเดตแท่งเทียนแบบวินาทีต่อวินาที ทำให้ข้อมูลในหน้า Details เป็นปัจจุบันเสมอ
* **Error Handling & Redirection**: หากไม่พบข้อมูลสินทรัพย์ที่เลือก ระบบจะพากลับหน้าหลักอัตโนมัติเพื่อป้องกันการทำงานผิดพลาด
